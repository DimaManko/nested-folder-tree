# File Structure Tree

Учебный проект (HW2): визуализация вложенной файловой структуры, которую приложение получает с локального API и рекурсивно отрисовывает в виде дерева папок и файлов.

## Что делает проект

- Загружает дерево из `db.json` через json-server (`GET http://localhost:3000/root`).
- Рекурсивно обходит узлы и рендерит папки (`Folder`) и файлы (`File`).
- Показывает состояния загрузки и ошибки.
- Отображает дерево в простой карточке с отступами для вложенности.

Стили (`src/index.css` и `className` на существующих элементах) написаны с помощью AI-агента в Cursor. Логика рендера дерева и запросы к API при стилизации не менялись.

## Технологии

| Технология | Назначение |
| --- | --- |
| React 19 | UI и рекурсивный рендер дерева |
| Vite | Dev-сервер и сборка |
| json-server | Локальный REST API поверх `db.json` |
| concurrently | Одновременный запуск фронтенда и API |
| ESLint | Линтинг |

Дополнительных UI-библиотек и `.env` нет: URL API задан константой в коде.

## Запуск

Нужны Node.js и npm.

```bash
npm install
npm run dev
```

Команда `npm run dev` поднимает сразу два процесса:

- Vite — фронтенд (обычно `http://localhost:5173`)
- json-server — API на `http://localhost:3000`

Откройте в браузере адрес Vite.

Отдельно:

```bash
npm run dev:vite      # только фронтенд
npm run dev:backend   # только json-server
npm run lint          # проверка кода
```

## Структура

- `src/App.jsx` — точка входа приложения
- `src/components/FolderList.jsx` — загрузка данных и рекурсивный вывод
- `src/components/Folder.jsx` / `File.jsx` — узлы дерева
- `src/hooks/useHttp.js` — обёртка над `fetch`
- `src/index.css` — стили интерфейса
- `db.json` — исходные данные файловой структуры
